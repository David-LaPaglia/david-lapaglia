Project Overview

This project from INFO 3510 (Music as Information) builds a Discord bot that helps users discover music through artist recommendations, lyrical exploration, and metadata lookups using external APIs.

Core Features

  • /sayhello member for user onboarding and command testing
  • /getRecs artist and /getRecsByCountry country for music discovery
  • /plotSingers artist and /getLyrics song, artist for exploration and analysis
  • /getArtistId artist and /getArtistInfo artistId for artist metadata

Technical Notes

  • Built in Python and developed in notebook format for rapid iteration
  • Uses Last.fm API for recommendations and artist-level data access
  • Combines chatbot UX with data workflows for music analytics
