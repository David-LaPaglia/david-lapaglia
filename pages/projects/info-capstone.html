Project Overview

Lectern is a full-stack web application designed to make it easier for university students to read and engage with their assignments. Built as the INFO 4700 Senior Capstone, it combines a Django back end with a React front end and runs containerized with Docker.

My Role & Contributions

I worked as a software engineer while integrating HCI research perspectives into the design and development process. My contributions spanned the full stack and the user experience:

  • Front-End Engineering: Built and styled React components for the student reading interface and dashboard.
  • Back-End Development: Contributed Django models, views, and API endpoints supporting assignment content and user data.
  • DevOps: Helped configure Docker and docker-compose orchestration for the Django, React, and PostgreSQL services.
  • HCI Research: Participated in user research and interface design activities to support accessible, student-centered reading workflows.

Tools & Technologies Used

  • React front end
  • Django / Django REST Framework back end
  • PostgreSQL database
  • Docker & Docker Compose
  • HTML, CSS, JavaScript
  • Human-Computer Interaction (HCI) research methods

Key Takeaways

  • Experience shipping features in a collaborative, full-stack team environment.
  • Balanced engineering constraints with user-centered design feedback.
  • Practiced containerized deployment and multi-service application architecture.
